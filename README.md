
# TranquilityCaps

Your all-in-one destination for stress relief, community wellness, affiliate health products, and online support for mental health.

## 🚀 Deploy It Now
- Use [Vercel.com](https://vercel.com) to connect this repo and deploy
- Or launch locally via:
  ```bash
  ./setup.sh
  ```

## 🧩 What's Included
- `index.html`: Homepage
- `product.html`: Buy TranquilityCaps via Stripe
- `donation.html`: Donate via PayPal
- `book.html`: Link to your stress relief book on Amazon
- `affiliate_reviews.html`: List of affiliate categories
- `audible.html`, `kindle.html`, `prime.html`, `music.html`: Individual affiliate landing pages
- `faq.html`: Product questions
- `testimonials.html`: Customer quotes
- `about.html`: Brand values and mission
- `email_signup.html`: Newsletter form (Mailchimp)
- `setup.sh`: Easy local deployment script

## 💰 Monetization Features
- Stripe product sales
- PayPal donation form
- Amazon affiliate trials
- Email collection for future promotions

## ✉️ Email Signup
- Configure your Mailchimp `form action` URL in `email_signup.html`

## 📘 Book Page
- Your book "The Science Behind Stress Relief" is promoted with a CTA and link to buy on Amazon

## ☁️ Hosting
- Fully static site, deployable for free on Vercel, Netlify, or GitHub Pages

## 💡 Tips
- Keep your links active and monitor affiliate performance
- Add Google Analytics or Facebook Pixel for tracking
- Push updates via GitHub for auto-deploy with Vercel
